\begin{abstract}
Test-time neural memory is increasingly proposed as the persistent-state
component of long-horizon sequence models, on the premise that a recurrently
updated state can retain information that attention windows discard. We ask a
simple question of one such module: \emph{how long does it actually remember?}
In a state-space recursion $M_t=(1-\alpha_t)M_{t-1}+S_t$, the forget gate
$\alpha_t$ is a memory horizon, $\tau=-1/\ln(1-\alpha_t)$. Reading $\alpha_t$
directly out of trained Titans models, we measure $\tau=0.74$--$1.16$ chunks,
i.e. \textbf{6--9 sequence positions against a 256-position context}---two to
four percent of what the model sees. We then show this is structural rather
than incidental: the paper's appendix specifies a per-dimension decay
$\mathrm{diag}(1-\alpha_t)$, but the implementation the field builds on emits
\emph{one scalar per head}, broadcast to all 256 memory units, so the memory
has exactly one timescale no matter how many dimensions it has. Causally, under
that scalar gate no hidden unit owns any stored association (largest
single-unit ablation effect $0.13$ cosine); granting units independent decay
rates restores localization in $8/8$ seeds, at a measurable cost to recall
fidelity. We also report an evaluation trap: the memory's residual path
inflates apparent recall, so that zeroing the entire memory MLP leaves all but
the two freshest associations unchanged. Our results are small-scale but
causal, and they bear on how persistent state in temporal models is specified,
implemented, and measured.
\end{abstract}

\section{Introduction}

Architectures that update a memory \emph{during inference}---test-time
training, neural memory, and state-space hybrids---are being adopted as the
persistent-state mechanism for long-horizon sequence modeling. Titans
\citep{behrouz2025titans} is a prominent instance: a small MLP whose weights are
rewritten chunk-by-chunk as the model reads, governed by a learned forget gate.

Temporal systems are the natural stress test for such a claim, because real
temporal data carries several periodicities at once and a memory must hold them
simultaneously. That requirement is the premise of multi-rate forecasting
architectures \citep{challu2023nhits}. It is also a precise, checkable property
of a recurrent memory: in
\begin{equation}
M_t = (1-\alpha_t)\,M_{t-1} + S_t,
\label{eq:update}
\end{equation}
the decay rate $\alpha_t$ \emph{is} a timescale, with time constant
$\tau=-1/\ln(1-\alpha_t)$ steps. A scalar $\alpha_t$ buys one timescale; a
per-dimension $\alpha_t$ buys as many as there are dimensions.

This paper asks what a deployed test-time memory actually provides. We make
three contributions. First, we \textbf{measure} the effective horizon of a
trained Titans memory and find it is a few percent of the context length.
Second, we trace this to a \textbf{specification/implementation gap}: the
architecture's own appendix writes the decay in per-dimension form, while the
implementation the community runs collapses it to a scalar. Third, we show the
\textbf{causal consequence} for what the memory can store, and identify a
measurement confound that inflates apparent retention.

\section{Setup, and what the gate actually is}

No official implementation of Titans has been released. We therefore study the
most widely used public reimplementation, which is the de facto Titans for work
building on the architecture.\footnote{Cited by URL in the camera-ready;
omitted here to preserve anonymity.} \textbf{Claims below are properties of that
implementation, not necessarily of the authors' unreleased code.}

Unless stated otherwise the memory is an MLP of shape $64\to256\to64$ ($256$
hidden units) inside a 4-layer Memory-as-Context transformer, $\mathrm{dim}=64$,
one memory layer, chunk size $8$, context $256$.

\paragraph{Specification.} Equation~\ref{eq:update} is Eq.~13 of
\citet{behrouz2025titans}, with $\alpha_t\in[0,1]$ and no per-unit index.
Appendix~C's fuller derivation writes the same recursion as
$\mathcal{M}_t = \mathrm{diag}(1-\alpha_t)\mathcal{M}_t + S_t$ (Eq.~32), with
$\mathrm{diag}(\eta_t)$ and $\mathrm{diag}(\theta_t)$ likewise (Eq.~33)---a
per-dimension form that would permit each memory dimension its own retention
rate. We note this appendix section argues Titans generalizes Gated DeltaNet,
so the diagonal form may be presentational; we report what is written rather
than inferring intent.

\paragraph{Implementation.} The module producing $\alpha_t$ is a linear map to
$\texttt{heads}$ outputs whose result is reshaped with a trailing dimension of
size one, then consumed by an associative scan. It therefore emits \emph{one
scalar per head per chunk}, broadcast identically across all $256$ hidden units.
The scalar form is what makes the parallel scan efficient---this is a known and
motivated trade, shared with Mamba-2 and Gated DeltaNet. Our contribution is not
that the gate is scalar, but what that costs.

The measured horizon is $\tau=0.74$--$1.16$ chunks, or $6$--$9$ sequence
positions against a $256$-position context: \textbf{2--4\% of what the model
sees}. The value is stable across training lengths and across seeds, and---as we
showed separately---barely moves between real text and random input, so it is a
property the model settles into during training rather than a live response to
what it is reading.

Two bounds on this claim. The memory's contribution is not the model's total
reach: attention and the residual stream carry information independently, so
this measures how fast \emph{the memory's} content decays, not how far the model
can see. And because the gate is a single scalar, there is no second, longer
timescale hiding in other units---one $\alpha$ is one $\tau$, for all $256$.

\section{What a single timescale costs}

\paragraph{No unit owns a fact.} We store $N$ tracked key/value pairs, ablate one
hidden unit at a time, and re-measure every pair's recall through the library's
own retrieval path (verified to reproduce the unmodified output at
$\cos\approx1.0$). The largest effect any single ablated unit had on any single
pair was $\mathbf{0.13}$ on a cosine scale, trained or untrained. Nothing
localizes.

\paragraph{The gate is the cause.} Instantiating Appendix~C's
$\mathrm{diag}(1-\alpha_t)$ directly---assigning each unit its own fixed decay
rate and changing nothing else---restores localization
(Table~\ref{tab:perunit}). Under uniform decay, $0/8$ seeds produced a unit
cleanly owning one pair; under spread decay, $4/8$ did, and even the
non-crossing seeds ran $5$--$7\times$ above uniform's ceiling in every seed.

\paragraph{But it is a trade, not a free win.} Per-unit decay is not simply
better. Measuring aggregate recall under capacity pressure, spread decay is
worse at every lag we tested---roughly $0.10$--$0.15$ against $0.39$--$0.65$ for
uniform---because spreading rates across $[0.02,0.98]$ leaves many units wiping
themselves almost every step. The diagonal form buys localizability and pays for
it in retention. We report this because it bounds the obvious prescription.

\section{An evaluation trap}

The default memory is $\mathrm{ResidualNorm}(\mathrm{MemoryMLP}(x))$, i.e.
$\mathrm{LN}(\mathrm{MLP}(q))\cdot\gamma + q$. Zeroing the \emph{entire} MLP---
removing all learned memory content---left most pairs' recall nearly unchanged;
only the two freshest showed a real contribution ($0.96\to0.59$,
$0.97\to0.57$). Most of what a naive read scores as recall is the residual path
returning the query.

Any evaluation of this architecture that does not zero the memory as a control
will overstate retention, and the overstatement is largest for exactly the old
items that long-horizon claims depend on.

\section{Preliminary: retention does not track input statistics}

Measuring the end-of-passage versus early write magnitude across corpora matched
for marginal entropy, the memory \emph{accumulated} in every case, including
i.i.d.\ noise with no learnable structure (ratio $3.03$, $2.86$, $4.27$ at
$256/512/1024$ units). We could not resolve a relationship with predictability
at this scale, and single-run variation was comparable to between-corpus
differences. We report this as a negative, exploratory finding. It is consistent
with the surprise-driven write of Eq.~14, under which unpredictable input keeps
producing large gradients and therefore large writes.

\section{Limitations}

All results are small-scale: a $256$-unit memory, short contexts, short training
runs. We study one architecture and one public implementation, and cannot verify
whether the authors' unreleased code shares the scalar-gate restriction. The
per-unit decay result assigns rates directly rather than learning them, so it
establishes that per-dimension decay \emph{permits} localization, not that
training would discover it. The horizon measurement is of the memory's decay,
not of the model's total context reach.
